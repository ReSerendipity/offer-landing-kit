# 到岗前作战包 · Offer → 入职 衔接工具

> 求职工具都在教你「怎么拿 offer」，没人管你「拿到之后怎么不翻车」。
> 这是一个纯前端的「最后一公里」管家：**离职交接 · 社保断档 · 试用期台账**，一站管稳。

![总览](assets/tab-handover.png)

## 在线体验

**https://reserendipity.github.io/offer-landing-kit/**

支持直达链接：

- `?tab=handover` — 离职交接清单
- `?tab=social&demo=1` — 社保断档测算（自动填入示例：北京，断档 47 天）
- `?tab=probation&demo=1` — 试用期台账（自动填入示例：入职日为 30 天前）

## 它解决什么

| 模块 | 场景 | 能力 |
|---|---|---|
| ① 离职交接清单生成器 | 离职交接总漏项，怕背锅 | 按岗位 / 团队规模 / 是否带人，生成 T-30 / T-14 / T-7 / 最后一天 四阶段可勾选清单 + 进度条；带人自动追加「下属安排」子项 |
| ② 社保断档测算器 | 社保断档影响购房 / 落户资格 | 输入城市、离职日、入职日，输出断档天数与补缴估算；按当地连续缴纳门槛给出风险等级（无断档 / 已断缴 / 超门槛） |
| ③ 试用期 100 天台账 | 试用期摸不清节奏 | 第 1 周 / 30 / 60 / 90 / 100 天里程碑时间轴，自动标注「已过 / 临近 / 未到」，转正答辩提前预警 |

## 特性

- **纯前端单文件**：HTML + 原生 JS，零依赖、零后端、零构建
- **数据不出本机**：所有输入与勾选状态仅存于浏览器 localStorage，不上传任何服务器
- **移动端可用**：响应式布局，手机浏览器直接打开

## 免责声明

社保城市门槛为公开资料整理的**示例值**，各地政策随时调整，且「连续缴纳」通常要求无中断——断档即清零、需重新累计。请以当地住建 / 人社官方口径为准；本工具仅作风险提示，不构成政策结论。
